# @nyxapi/core

Framework-independent runtime for NyxAPI: a Fetch-based HTTP client, a query cache (single-flight dedup, freshness, retries, cancellation, GC, invalidation, infinite queries, dehydrate/hydrate), a mutation engine with patch-based optimistic updates, and the callable endpoint runtime used by generated clients.

```ts
import { createNyxClient } from "@nyxapi/core";

const nyx = createNyxClient({ baseUrl: "https://api.example.com/v1", getToken: () => token });
```

Used by clients generated by `nyx` from OpenAPI or Swagger; GraphQL and tRPC adapters (`@nyxapi/graphql`, `@nyxapi/trpc`) build on its protocol-neutral operations (`createQueryOperation`, `createMutationOperation`). Pre-1.0: the API may change. See the repository docs (`docs/API-DESIGN.md`) for the contracts. ESM only, Node >= 22.12 and modern browsers.
