# @syncapi/core

Framework-independent runtime for syncapi: a Fetch-based HTTP client, a query cache (single-flight dedup, freshness, retries, cancellation, GC, invalidation, infinite queries, dehydrate/hydrate), a mutation engine with patch-based optimistic updates, and the callable endpoint runtime used by generated clients.

```ts
import { createNexClient } from "@syncapi/core";

const nex = createNexClient({ baseUrl: "https://api.example.com/v1", getToken: () => token });
```

Usually used together with a client generated by `@syncapi/cli`. Pre-1.0: the API may change. See the repository docs (`docs/API-DESIGN.md`) for the contracts. ESM only, Node >= 22.12 and modern browsers.
